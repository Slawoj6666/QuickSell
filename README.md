# Cel Projektu
Celem projektu jest stworzenie prostego portalu do sprzedwania i kupowania żecyzy od innych użytkowników.

# użyte technologie
do frontendu jest użyty React, a dla backendu Nmp node.js
Bazy dane użyte do projektu to:

mongodb:
dla wiadomości czatu i atrybut ogłoszeń.
PostgreSQL:
dla użytkowników,kategori, ogłoszeń i obserwowanych.

# jak urochomić?
W CMD wejść w folder projektu i użyc `npm run dev` co uruchomi server i klient
